# Claude Static Review v4 Result Archive

This directory preserves the original output generated by Claude Code during its static code review of the AppSec v1 vulnerable version.

## Result status

- Review method: static code review only
- Dynamic requests: 0
- Current status: Claude draft awaiting Security Engineer adjudication
- Confirmed findings: none
- Confirmed severity ratings: none

The eight files under `raw/` are Claude's original outputs. They must remain unchanged after archival. `result-manifest.json` records each file's size and SHA-256 digest so that evidence integrity can be verified. Later decisions to accept or reject a finding, assess its impact, and assign severity belong in a separate adjudication record and must not rewrite Claude's original report.

## Files

- `raw/static-review-log.json`: static review activity and evidence log
- `raw/findings.json`: machine-readable review results and unexecuted test matrix
- `raw/findings.md` and `raw/findings.en.md`: Chinese and English review reports
- `raw/remediation-advice.md` and `raw/remediation-advice.en.md`: Chinese and English draft remediation advice
- `raw/limitations.md` and `raw/limitations.en.md`: Chinese and English limitations
- `result-manifest.json`: provenance, status, and file-integrity manifest for this run

These materials contain an independent reviewer's candidate conclusions only. The Security Engineer makes the final decision about whether each item is a valid security finding based on the approved requirements, scope, and evidence.
